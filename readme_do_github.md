# 🧬 Biologia Quest — Plataforma Educativa Interativa

O **Biologia Quest** é uma aplicação web interativa desenvolvida para auxiliar estudantes do 2º ano do Ensino Médio no aprendizado e revisão de tópicos fundamentais de Biologia para provas escolares e vestibulares.

---

## 📌 Conteúdos Abordados

1. **Desenvolvimento Embrionário**
   - Fecundação (interna vs. externa).
   - Clivagem / Segmentação (Mórula e Blástula).
   - Gastrulação e Folhetos Embrionários (Ectoderma, Mesoderma, Endoderma).
   - Neurulação (Tubo neural e Sistema Nervoso).
   - Organogênese e Classificação Embrionária (Diblásticos, Triblásticos, Celoma e Destino do Blastóporo).

2. **Platelmintos**
   - Características gerais (corpo achatado, acelomados, simetria bilateral).
   - Classificação (Turbelários, Trematódeos e Cestódeos).
   - Parasitoses: Esquistossomose, Teníase e Cisticercose.

3. **Nematelmintos (Nematódeos)**
   - Características gerais (corpo cilíndrico, pseudocelomados, tubo digestivo completo com ânus).
   - Parasitoses: Ascaridíase, Ancilostomose (Amarelão), Oxiurose e Filariose (Elefantíase).

---

## 🚀 Funcionalidades

- **Gamificação Integrada:** Ganho de Experiência (XP), subida de níveis, medalhas e contador de frequência de estudo.
- **Aulas Interativas:** Conteúdo em etapas curtas e de fácil digestão.
- **Quizzes por Aula:** Testes imediatos de fixação ao término de cada aula.
- **Simulado Integrado:** Banco de questões no formato de provas escolares com nota automática e explicação das respostas.
- **Modo Revisão Rápida:** Resumos de última hora e tabelas comparativas.
- **Persistência de Dados:** O progresso do estudante é salvo automaticamente via `localStorage`.

## 💻 Como publicar no GitHub Pages

1. Crie um novo repositório no seu GitHub chamado `biologia-quest`.
2. Adicione os arquivos `index.html` e `README.md` na raiz do seu repositório.
3. No repositório no GitHub, vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e clique em **Save**.
5. Em alguns instantes, o GitHub fornecerá o link público da sua aplicação no ar!
